# English Workbooks

Self-study workbooks on English grammar, one topic per book. Each book covers its topic completely: a diagnostic, a decision procedure, rules with worked examples and exceptions, three kinds of exercise per rule, and parallel mastery tests. Every answer key is in the book. *English Verb Frames* adds a checkpoint after each part, an index of every frame it teaches, and a one-page checklist for checking your own writing.

The books are written for adult learners who read English well but make habitual errors in writing. They use American English. Each book names the first-language habits behind the errors it corrects: *English Articles* those of a language with no articles, and *English Verb Frames* those of Ukrainian, which it cites in its explanations and in a map of calques.
