# English Workbooks

Self-study workbooks on English grammar, one topic per book. Each book covers its topic completely: a diagnostic, a decision procedure, rules with worked examples and exceptions, three kinds of exercise per rule, and parallel mastery tests. Every answer key is in the book. Each book also ends with tools for checking your own writing: a checklist, a table of the mistakes each rule catches, and a map of calques. *English Verb Frames* adds a checkpoint after each part and an index of every frame it teaches.

The books are written for adult learners who read English well but make habitual errors in writing. They use American English. Each book names the first-language habits behind the errors it corrects: *English Articles* those of a language with no articles, and *English Verb Frames* those of Ukrainian. Both cite Ukrainian phrases in their maps of calques.
